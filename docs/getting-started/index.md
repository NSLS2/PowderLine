# Get started

New to PowderLine? Work through these in order.

1. [Install](install.md) PowderLine and an engine.
2. [Your first refinement](first-refinement.md): run a complete refinement
   of LaB6 and read the results.
3. [Analyze your own data](your-own-data.md): write a recipe for your
   pattern and structure, validate it and run it.

To understand what is happening along the way, read
[How PowderLine works](../concepts/how-powderline-works.md).
